OS base: 0x82000000
P1 base: 0x82100000
P2 base: 0x82200000

Generated files:
- Beagle/os_beagle.bin
- Beagle/p1_beagle.bin
- Beagle/p2_beagle.bin
- qemu/os_qemu.bin
- qemu/p1_qemu.bin
- qemu/p2_qemu.bin

U-Boot example sequence:
loady 0x82000000    # send Beagle/os_beagle.bin
loady 0x82100000    # send Beagle/p1_beagle.bin
loady 0x82200000    # send Beagle/p2_beagle.bin
go 0x82000000

Direcciones en las que se carga en QEMU
os > 0x00010000
p1 > 0x00020000
p2 > 0x00030000

*If you want to execute QEMU use "make runqemu"
*Make builds both versions, QEMU and BEAGLEBOARD
*Use "make qemu" or "make beagle" to build only one platform

NOTE: Do not load P2 at 0x82000000. That overwrites the OS.
